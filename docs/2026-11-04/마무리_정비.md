## 2. 항목별 내용

### 2.1 OpenAI `store=False`
- 요청·응답을 OpenAI 쪽에 저장하지 않도록 명시했다. 공식 문서의 기본값 설명이 서로 달라 코드에서 고정한다.
- 보내는 내용은 같고 보관만 줄인다. 악용 감시 로그(최대 30일)는 이 값과 무관하다.
- 확인: 로컬에서 요청 본문을 만들어 보니 `store: false`가 들어간다(전송은 하지 않음).

### 2.2 effort 정리
- 다듬기 effort가 코드에 `low`로 고정돼 있던 것을 `.env`의 `REWRITE_EFFORT`로 뺐다. **기본값은 그대로 low**라 동작은 바뀌지 않는다.
  - gpt-5.4-mini의 기본은 none이라, low는 다듬기에서 생각 토큰을 더 쓴다(11-02 시험에서 78개). 나중에 속도를 더 줄이고 싶으면 `REWRITE_EFFORT=none`으로 바꾼다. 다만 평가 없이 바꾸는 것이므로 체감 확인 정도로만 쓴다.
- gpt-5.4-mini 허용값(none·low·medium·high·xhigh)에 맞춰 `xhigh`를 그대로 넘기고 `max`만 `xhigh`로 바꾼다. 전에는 xhigh도 high로 낮췄다. `none`은 OpenAI 전용이라 Claude에서는 지정하지 않은 것과 같다.
- 현재 값(`ANSWER_EFFORT=low`, 다듬기 low)에는 영향이 없다.

### 2.3 Gradio 기록 끄기
- `ChatInterface(flagging_mode="never", save_history=False)`: flag 기본값은 환경 변수(`GRADIO_CHAT_FLAGGING_MODE`)에 따라 바뀔 수 있어 고정했다. flag가 켜지면 대화 전체가 `.gradio/flagged/`에 쌓인다.
- `launch(run_history=False)`: gradio 6.31은 실행 기록을 기본으로 남기고, 기록 화면에서 Hugging Face 저장소로 보낼 수도 있다.
- `.gitignore`에 `.gradio/` 추가.

### 2.4 Hugging Face 오프라인
- `chat.py` 맨 앞에서 `HF_HUB_OFFLINE=1`을 기본으로 둔다. gradio가 import될 때 huggingface_hub 설정을 읽으므로 `.env`로는 늦다.
- 확인: 오프라인 상태에서 임베딩(bge-m3)과 리랭커(bge-reranker-v2-m3)가 캐시에서 정상 로드됐다.
- 새 모델을 받아야 할 때만 셸에서 `HF_HUB_OFFLINE=0`으로 실행한다.

### 2.5 다듬기 타임아웃
- 채팅 화면에서만 다듬기를 `REWRITE_TIMEOUT`(5초) 안에 못 받으면 **재시도 없이** 원래 질문으로 검색한다. 화면에는 기존처럼 "검색어 다듬기 실패 → 원래 질문으로 검색"이 뜬다.
- 평가 스크립트는 타임아웃을 걸지 않는다. 걸면 검색어가 조용히 원래 질문으로 바뀌어 평가가 흔들리기 때문이다.
- 답변 스트리밍에는 걸지 않았다(라이브러리 기본값).

### 2.6 질문 길이 상한
- 질문이 `MAX_QUESTION_CHARS`(300자)를 넘으면 LLM을 부르지 않고 "질문이 너무 깁니다 … 외부로 전송하지 않았습니다"를 보여 준다.
- 긴 문서를 붙여 넣으면 그 전문이 다듬기·답변 두 번 외부로 나가는 것을 막는다.

## 3. 리랭커 입력 확정: 다듬은 검색어

| 근거 (11-03 문서 1절, Claude 평가) | Hit@1 | MRR | 여러 조항 Recall@4 |
|---|---:|---:|---:|
| 1세트 후보 5 + 원래 질문 → 다듬은 검색어 | 0.80 → **0.89** | 0.90 → **0.93** | 0.69 → 0.76 |
| 2세트 후보 5 + 원래 질문 → 다듬은 검색어 | 0.82 → 0.82 | 0.91 → 0.91 | 0.65 → 0.69 |

- 두 세트 모두 다듬은 검색어가 같거나 낫다. 후보 수는 5개 그대로(`RERANK_CANDIDATES=5`).
- `chat.py`와 `eval_answers.py`가 다듬은 검색어로 리랭크한다. 다듬기가 실패하거나 꺼져 있으면 원래 질문과 같다.
- 한계: 이 수치는 Haiku가 다듬은 검색어 기준이다. 지금은 gpt-5.4-mini가 다듬으므로 실제 효과는 다를 수 있다. 오늘 원칙에 따라 따로 재지 않는다.
- `eval_retrieval.py`의 `--rerank-query` 기본값은 실험 도구라 original 그대로 둔다.
