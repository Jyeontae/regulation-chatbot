# 후속 질문: 직전 질문 함께 보내기 (2026-11-04)

> 11-03 개선 조사 E3(후속 질문)을 구현했다. 사용자 요청: "히스토리까지 같이 가져오도록".
> API 호출과 평가는 하지 않았다. 이 문서에는 규정 내용이 없다.

---

## 1. 무엇이 바뀌나

전에는 질문마다 독립적으로 처리해서 이런 대화가 안 됐다.

| 순서 | 질문 | 전 | 후 |
|---|---|---|---|
| 1 | "경조사 휴가 며칠이야?" | 정상 | 정상 |
| 2 | "그럼 계약직은?" | "계약직"만으로 검색 → 엉뚱한 조문 | 직전 질문을 참고해 "계약직 경조사 휴가 일수" 같은 검색어로 바꿔 검색 |

## 2. 설계

| 항목 | 결정 | 이유 |
|---|---|---|
| 무엇을 보내나 | 같은 대화의 **직전 사용자 질문**만 (기본 2개, `HISTORY_TURNS`) | 외부 전송을 질문으로 한정. 이전 답변을 넣으면 이전 답의 오류가 다음 답으로 이어진다 |
| 어디에 넣나 | 다듬기 호출과 답변 호출 **둘 다** | 다듬기만 넣으면 검색은 맞아도 답변 LLM이 "그럼 계약직은?"만 보고 무엇을 묻는지 모른다 |
| 프롬프트 위치 | 사용자 메시지 맨 앞의 `[이전 질문]` 블록. 지시 문장도 이 블록 안에 둔다 | 직전 질문이 없으면 프롬프트가 **평가 때와 글자 하나까지 같다**. 그래서 지금까지의 평가 결과가 그대로 유효하다 |
| 새 주제 | 대화 지우기(휴지통) 버튼 | Gradio 기본 버튼으로 충분. 블록에 "새 주제면 무시"도 적었다 |
| 거절된 질문 | 직전 질문에서 뺀다 | 300자를 넘어 거절된 질문은 외부로 보낸 적이 없으므로 이후에도 보내지 않는다 |
| 화면 표시 | 직전 질문을 썼으면 답변 맨 위에 "이전 질문 N개 참고" | 무엇이 함께 갔는지 사용자가 알 수 있게 |
| 평가 스크립트 | 쓰지 않음 (변경 없음) | 평가셋은 단일 질문이다 |

## 3. 바뀐 파일

| 파일 | 변경 |
|---|---|
| `src/regbot/rag.py` | 답변·다듬기 프롬프트에 `{history}` 자리(기본값 빈 문자열), `format_history()`, `rewrite_query_with_usage(..., history)` |
| `src/regbot/config.py` | `HISTORY_TURNS` (기본 2) |
| `scripts/chat.py` | `previous_questions()`로 Gradio 히스토리에서 직전 질문 추출, 다듬기·답변에 전달, `--history` 옵션, 시작 시 전송 안내 한 줄 |
| `.env.example`, `README.md` | 설정·설명 추가. README의 "이전 대화는 쓰지 않는다" 문구 교체 |

## 4. 확인

| 확인함 (로컬, 전송 없음) | 확인 안 함 |
|---|---|
| 직전 질문이 없을 때 답변·다듬기 프롬프트가 예전과 완전히 같음 | 실제 후속 질문에서 다듬기가 빠진 대상을 잘 채우는지 (API 호출, 사용자 확인) |
| 히스토리 추출: 문자열·목록 두 형식, 답변 제외, 300자 초과 질문 제외, 최근 N개만, 0이면 끔 | 직전 질문이 새 주제인데 다듬기가 억지로 섞는 경우의 빈도 |
| 컴파일, `--history` 옵션 | |

## 5. 직접 확인할 것

채팅 화면에서 아래 순서로 물어본다.
1. 규정에 있는 질문 하나 → 정상 답변인지
2. "그럼 ○○는?"처럼 대상만 바꾼 후속 질문 → 맨 위에 "이전 질문 1개 참고"와, 빠진 내용이 채워진 검색어가 나오는지
3. 전혀 다른 주제 질문 → 검색어에 앞 주제가 섞이지 않는지 (섞이면 대화 지우기)

섞이는 일이 잦으면 `HISTORY_TURNS=1`로 줄이거나 `--history 0`으로 끈다.

## 6. 외부 전송 변화

11-03 결정 질문 8번("직전 질문 1~2개를 다듬기 LLM에 다시 보내는 것을 허용하는가")은 이번 요청으로 허용된 것으로 본다. 답변 호출에도 같이 가므로, 질문 하나당 외부로 가는 양은 직전 질문 최대 2개(각 300자 이하)만큼 늘어난다. OpenAI 전송의 승인 범위 확인(미결)에 이 항목도 함께 포함한다.
